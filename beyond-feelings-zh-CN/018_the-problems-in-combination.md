# 第 15 章　思维问题的交织

前面，我们考察了第六至第十四章中的各种问题单独出现时的情形。它们确实常常单独发生，但以不同组合一起出现，至少同样常见。例如，“我的更好”的思维，会让我们抗拒那些挑战珍爱信念的新观念；从众冲动可能让我们接受对人或制度的刻板印象，而刻板印象又可能使我们作出无根据的假定，或把复杂情况过度简化。可能的组合不计其数，但它们有一个共同点：叠加起来，比其中任何一种问题单独出现时，都更妨碍批判性思维。

## 考察交织在一起的思维问题

下面仔细分析几个例子，看看不同问题如何相互作用，具体影响当事人的思考。

### 克劳德：政党认同与维护面子

克劳德是所属政党的积极活动者。他对党派有强烈的个人认同，因而坚信，党的纲领及候选人就是国家的救星，做起事来格外热忱。一天，他与业务上认识的内尔共进午餐。两人的谈话不出所料地转向政治。克劳德开始对本党候选人和对手作出一番断言：他支持的那位女候选人，理论和实践能力都出类拔萃；而她的男性对手，简直就是个彻头彻尾的傻瓜。他严厉抨击对手的政治履历、家人和同伴，滔滔不绝地说，一旦对方当选，国家就会毁于一旦。

听了一阵后，内尔提出质疑。她平静地列举事实，反驳克劳德的许多说法，指出他的断言夸大其词。虽然内尔的质疑并不针对个人，表达也冷静、客观，克劳德还是生气了。他指责内尔歪曲自己的话，否认自己确实说过的某些内容；对于另一些说法，即使内尔已拿出反面事实，他仍固执地坚持。

用我们已经学过的思维问题，重新梳理这段经过。克劳德最初的问题，是“我的更好”的态度。它让他看不到另一种可能：本党候选人和纲领并不完美，反对党也有可取之处。换句话说，他过高评价自己认同的事物，过低评价自己不认同的事物。因此，谈到候选人和纲领时，他很容易过度简化。随后，内尔指出他的错误——迟早会有人这么做——他便为了摆脱尴尬，使出了维护面子的招数。一个人投入得越深，就越不愿承认错误，所以克劳德无疑没从这次交锋中学到多少东西。

### 阿尔玛：抗拒时尚变化

阿尔玛穿着十分保守，强烈抵制任何时尚变化。迷你裙重新流行时，她简直不能接受。她常说：“如今的设计师不过是一群变态，一心想摧毁端庄的观念，助长道德败坏。”

与克劳德一样，阿尔玛也受到几种思维问题的共同影响。[原文此处残缺，后半句涉及对新事物的看法，以及夸大此事的重要性。] 这种视角使她对迷你裙设计师的品格和意图草率地下了结论，又把这一结论过度推广到所有设计师身上。

### 萨姆：归属感与选择性接受观点

十年前，萨姆结识了一群性关系随意、伴侣众多的人。起初，他对是否加入有所保留。毕竟，这些人对性和婚姻的态度，与他从小接受的观念非常不同。可是，这个圈子看起来那么刺激、那么现代、那么“跟得上时代”。萨姆非常渴望得到他们的接纳和赞许。融入以后，他开始购买赞美群体性行为、抨击传统性观念的书籍，还参加一些讲座，听人把随意的多伴侣性行为说成开明、解放人性的做法。如今，萨姆想当然地认为，所有这样做的人都思想勇敢、心理健康；而忠于单一伴侣的人则不肯思考、胆小畏缩、压抑自己。此外，他还认为，关于艾滋病的警告，源于清教徒式的、对性表达的厌恶。

萨姆的从众冲动强得对自己有害。他渴望受欢迎，渴望属于“时髦圈子”，以至于失去了自己的独立性。他不是经过仔细思考，权衡这个群体的优缺点和价值观，最终因为认同而加入；他只是想被接纳。这种从众冲动，也让他放弃了批判性的辨别。他没有兼读支持与反对随意性行为的分析，而是忽略所有负面评价，甚至连利弊兼谈的观点也不看。长期处于这种狭窄、封闭的视角中，他对两类人的看法都落入了刻板印象。[原文此句中段残缺；这里只译出可辨认的意思。] 这种视角也让他在艾滋病风险问题上采取了愚蠢的立场。

## 避免问题相互叠加

各种问题一旦交织，就会成倍增加批判性思维的障碍。一个错误强化另一个错误，又触发第三个错误，如此连锁下去。而且，这种连锁反应虽然通常先发生在某一领域——克劳德是政治，阿尔玛是时尚，萨姆是性——却常常蔓延到其他领域，影响我们在那些领域的思考。一个人若放任自己在生活的某一方面不加思索地作反应，往往只会变得更加不愿思考，而不会相反。原因很简单：日常生活中的许多问题本来就复杂，而人们普遍容易受诱惑，想用最快捷、省力的方式处理它们，现成而包办一切的答案，便具有不可否认的吸引力。

解决交织在一起的问题，与解决单个问题一样，第一步也是最重要的一步，就是承认自己容易犯这些错误。它们不是“别人的毛病”，也不只困扰没受过多少教育或不够聪明的人。每个人身上，都能在不同程度上找到它们。

另一个有用的办法，是不时提醒自己：每一种问题具体是什么，怎样应对最有效。为便于复习，下面简要汇总第六至第十四章讨论过的所有问题。

| 思维问题 | 如何识别与应对 |
| --- | --- |
| “我的更好” | 仅仅因为某个想法属于自己，就偏爱它。提醒自己，人人都有这种倾向，但批判性思维要求我们像审视别人的想法一样，审视自己的想法。 |
| 抗拒改变 | 偏爱熟悉的观念，排斥陌生的观念。预先意识到，自己对新观念的第一反应可能是否定；先把这种反应放到一边，再根据审慎评估作判断。 |
| 从众 | 因为群体压力或渴望归属，就跟别人一样想；或者反过来，仅仅为了与别人不同，就采取相反想法。让思考依据证据，而不是依据别人想什么、不想什么。 |
| 维护面子 | 当不愉快的现实威胁到自我形象或自己在他人眼中的形象时，设法保全形象。分清“希望如此”与“事实如此”，对自己诚实。 |
| 刻板印象 | 对人、地方或事物作僵硬不变的概括。提醒自己，多数事物无法整齐归入固定类别。刚开始搜集信息，就觉得“我已经知道正确判断是什么”时，要抵制这种感觉。 |
| 过度简化 | 简化不再只是把复杂问题缩减到便于理解的程度，而是歪曲、扭曲了问题。确保自己的观点准确反映现实。 |
| 草率下结论 | 证据尚未充分，就先作出判断。所有重要问题都得到回答后，再下结论；若证据不足却必须作答，就使用“如果……那么……”的方式；若证据只能支持可能性而非确定性，结论也应仅限于可能。 |
| 无根据的假定 | 未经察觉便已存在于心中、影响推理的观念，也就是想当然的看法。养成阅读时看懂字里行间、倾听时听懂弦外之音的习惯，找出那些没有明说、却明显隐含的观念。 |
| 逻辑谬误 | 对问题进行推理时出现的具体错误。监测自己的思考，留意这些错误的迹象，尤其是在准备口头或书面表达观点时。 |

## 应用练习

### 1. 分析问题的组合

仿照本章对克劳德、阿尔玛和萨姆的分析，考察以下案例。

#### 案例一：父母的震惊

中年夫妇安和丹得知，二十二岁、正在读大学四年级的女儿是一名女同性恋者，并且有同性性关系。他们极为震惊。从小接受的观念告诉他们，女同性恋是有意选择的道德堕落。面对这个新发现，两人一时难以接受，开始互相指责。安认为，丹一直对女儿冷漠疏远；丹则认定，安与女儿过于亲近，爱得让她透不过气。争吵了几个小时后，两人决定，女儿“越轨”还有一个更直接的原因：大学。安喊道：“把那么多女生挤在宿舍里，有文化的人难道不该警惕道德败坏的危险吗？”丹吼道：“见鬼，我要给那所大学的董事会主席写信。我要求开除学生事务主任！”

#### 案例二：斯蒂芬的成绩

斯蒂芬成为进步技术学院的一年级新生。他发现自己每周有三天要在早上八点上英语课，因为喜欢睡懒觉，心里很不高兴。但第一次上课时，他注意到教师姓斯坦，便暗自高兴：“哇，一个爱睡懒觉的犹太孩子，还有什么比遇上犹太老师更走运的？”随后几周，他抓住一切借口在课后留下来，与斯坦先生交谈，争取他的好感。前两篇作文，他专挑能突出自己犹太身份的题目，借此给斯坦先生留下印象。很快，他就认定斯坦先生“懂”他。

于是，他开始偶尔逃课，四次作业大约只交一次。见到斯坦先生，他便不断诉说自己种种可怜的不幸遭遇。期中成绩是 D，他却告诉自己，老师只是在吓唬他，最后会把分数提上去。此后，他更少上课，作业也做得更少。学期结束，英语成绩是 F。

他的第一反应是不敢相信，急忙去找斯坦先生。老师说：“第一天上课我就讲清楚了，只有认真上课、按时完成作业，才有可能及格。这个成绩让我遗憾，但它反映的就是你的表现。”从此，斯蒂芬在校园遇到斯坦先生便不肯打招呼；每逢小吃部或宿舍里谈起教师，他都会大声痛斥斯坦先生是个骗子。

### 2. 一场学术骗局

南加利福尼亚的三位医学教授设计了一场骗局，作为实验。他们付钱请一名职业演员，为三组教育工作者演讲。演员使用虚构身份——“阿尔伯特·爱因斯坦大学迈伦·L. 福克斯博士”，配上同样虚构却令人印象深刻的资历，再选一个听起来很学术的题目：《数学博弈论在体育教育中的应用》。接着，他便一句接一句地讲出毫无意义、彼此矛盾的话，把故弄玄虚的表达和学术术语混在一起。到了问答环节，回答更是前言不搭后语。

然而，听众中的五十五位教育工作者，没有一人发现自己受了骗。几乎人人都相信有所收获，有人甚至这样称赞这位冒牌专家：“演讲精彩，听得很享受。态度热情……例子生动……口齿极为伶俐。”[^1] 请解释，第六至第十四章讨论的哪些问题可能相互作用，导致听众如此轻信。

### 3. 形成自己的立场

判断你对以下案例的立场，注意避免本章复习的所有思维问题。

1. 阿拉巴马州的监狱和拘留设施严重超员，一名美国联邦地区法院法官下令，让三百多名罪犯提前获释，其中包括杀人犯、强奸犯和累犯。法官的理由是，严重拥挤侵犯了囚犯免受“残酷和异常惩罚”的权利。[^2] 你认同这位法官的观点吗？
2. 美国法律给予多数慈善和教育团体免税资格，条件是它们不从事游说活动。不过，美国退伍军人协会和海外战争退伍军人协会等退伍军人组织，历来被视为例外。它们可以就巴拿马运河条约的批准、阿拉斯加国家公园、国家安全、周六邮件投递，以及更直接涉及退伍军人的议题展开广泛游说，而不影响免税资格。1982 年，一家联邦上诉法院取消了这种特殊待遇，理由是它违反宪法规定的平等保护原则。[^3] 你赞同这一判决吗？

### 4. 评估论证

仔细评估以下各项论证，判断哪一种立场最合理，以及为什么。避免本章复习过的思维问题。不要预先认定这里的观点一定有错，它也可能没有任何错误。

1. 多年来，罪犯把自己生平故事的版权卖给出版商和电影制片人。罪行越骇人，出版商和制片人通常就越愿意多付钱。这实际上是在奖励犯罪，应当停止。罪犯通过这种方式获得的收入，应转入一项基金，分配给其犯罪行为的受害者。

2. 《新约》中记载了圣保罗的这些话：“人人都应顺服在上掌权者，因为没有权柄不是出于上帝，现有的权柄都是上帝所设立的。所以，抗拒掌权者，就是抗拒上帝的安排；抗拒的人必自取刑罚。作官的原不是叫行善的人惧怕，而是叫作恶的人惧怕。你愿意不惧怕掌权者吗？只要行善，就会得到他的称赞……所以必须顺服，不只是因为惧怕刑罚，也是为了良心。”[^4] 从这些话可以清楚看出，所有基督徒都有义务忠于本国政府，不应挑战它。因此，生活在美国的基督徒参加任何抗议运动都是错误的；甚至支持外国的抗议运动，例如波兰团结工会运动，也是不对的。

3. 美国普遍有一种看法：审查那些被认为令人反感的书籍或其他材料，是不民主的行为。这个看法是错的。如果一本书、一本杂志、一张立体声唱片或一盒录像带，包含在思想上背离美国生活方式的观念，负责任的公民不仅有权，而且有义务阻止它继续流通。涉及孩子时，这种义务尤其重大。我们不会袖手旁观，让自己的孩子或邻居的孩子喝毒药，而会拿走毒药并处理掉。对毒害心灵的东西，我们为什么要比对毒害身体的东西少一分警惕？

4. 近年来，对吸烟者的限制越来越多。过去，人们随时随地都能点烟；如今，反烟游说团体已经在许多航班、办公室和各种公共场所推动了禁烟，还让餐馆把吸烟者单独隔开。这些做法全都侵犯了吸烟者的权利。吸烟对健康的风险本来就被夸大了；即使真有风险，只要我愿意拿自己的健康冒险，那也是我自己的事，与别人无关。如果同事不想让我的烟飘到她那边，买一台小型空气净化器就是了。如果飞机乘客想给自己设一个专门的禁烟区，我不会反对；但当我要求设吸烟区时，他们也无权反对。

5. 1983 年，美国最高法院裁定，可以把驾驶人拒绝接受血液酒精检测的行为，作为对其不利的证据。[^5] 我认为法院作错了决定。一个人拒绝检测，可能是因为知道自己醉了，但原因不止这一种。一个清醒的人，也可能因为觉得检测侵犯隐私而拒绝。在这种情况下，法官和陪审团很可能把这项“证据”解释为有罪的迹象，从而让无辜者被判有罪。

6. 一位女性给“亲爱的艾比”专栏写信，抱怨儿子结婚时要改用未婚妻的姓。艾比回答，年轻人已经成年，有权自行决定，母亲应该大方地接受。在我看来，这是糟糕透顶的建议。一个男人这样向未婚妻的压力屈服，婚姻一开始就走错了方向。再说，男人放弃自己的姓氏，既古怪，又没有男子气概。他的家人有权期待他延续家族姓氏。向来如此，也应该一直如此。

7. 在一些大学，如果宿舍某一层出现财物损坏，又找不到责任人，维修费就由该层全体住户分摊。这种政策不公平。有时，损坏是来访的外人造成的；即使责任人确实住在该层，让无辜的人付钱也不公平，其中许多人甚至不知道损坏发生在何时、由谁造成。如果校方查不出责任人，就不该向任何人收费。
