# 第 18 章　厘清议题

许多人把分析的范围划得过大，超出了自己的驾驭能力。他们拿不准某个主题的一个方面是否足够展开，于是干脆把整个主题都纳入讨论。不幸的是，将所有方面混在一起、不加区分，容易让人忽视重要差别，漏掉细微之处，扭曲观念之间的关系。以此为起点的探究与判断，很可能既肤浅又过于简单。

善于分析的人则明白，只要认真探究，即使是一个议题中很小的方面，通常也有足够多的话可说。他们知道，高质量的分析，尤其是对争议问题的分析，往往要求把焦点收得很窄。他们也清楚，除非打算写一本大部头著作，否则要分析得深入，就必须舍弃广度。换句话说，他们领会了“少即是多”这句话的智慧。

## 怎样厘清议题

要让思考尽可能富有成效，我们也应像善于分析的人那样，适当限定主题。一开始就要确定：在那个宽泛的大议题中，我们究竟关注哪一个或哪几个方面。选择焦点时，不能停留在粗略、模糊的认识上，而要力求精确。下面三个步骤，可以帮助我们迅速而有效地选择和厘清议题。

1. **尽量列出所选大议题之下的具体分题。**如果这是一个重要而有争议的问题，清单上可能会有十几个分题。每一个本身都是较小的议题，都值得运用批判性思维来分析。
2. **明确决定自己要研究哪一个具体议题。**我们很少能充分处理所有分题。选择的一个或几个分题，不仅应符合自己的兴趣，还应符合分析的场合、目的，以及可用的时间和篇幅。
3. **把选定的具体议题，写成一个或几个清晰、聚焦的问题。**这样做有助于后续探究保持焦点，避免偏题。把问题写下来后，每当思路转向某个方向，只需看一眼这些问题，就能判断那个方向是否可能带来有益成果。

下面看看，这三个步骤如何用于实际议题。

## 示例议题：堕胎

1973 年 1 月，美国最高法院在“罗诉韦德案”中判定堕胎合法。然而，进入 20 世纪最后十年时，美国人对此仍然存在严重分歧。与大多数争议问题一样，堕胎并非一个单一议题，而是一组较小议题的集合。讨论堕胎，如果一开始没有意识到这一点，就很难作出有价值的贡献。

我们的三步法，可以帮助你将这一组议题分别理清，并展开有意义的讨论。为简洁起见，下表左栏列出你最初可能想到的分题，右栏则展示：决定关注该分题后，可以怎样进一步把它提炼成问题。

| 分题 | 具体问题 |
| --- | --- |
| 女性对自己身体的权利 | 女性是否有权决定怎样使用自己的身体？如果有，胎儿是否应被视为她身体的一部分？ |
| 医生的职责 | 医生是否只对患者，也就是女性本人，负有义务，还是也对胎儿负有义务？ |
| 胎儿的地位 | 如果胎儿会在妊娠期间成为一个人，那么是从什么时候开始？ |
| 法律的作用 | 如果胎儿在妊娠的某个阶段成为一个人，执法者，也就是警察和法院，是否有义务保护它的权利？ |
| 妊娠阶段 | 如果允许堕胎，应该允许在妊娠的哪些阶段进行？前三个月？前六个月？出生前任何时候？ |
| 女性的年龄 | 决定是否允许堕胎时，是否应该考虑女性的年龄？十三岁的孩子是否应与四十岁的女性同样对待？ |
| 强奸与乱伦情形 | 强奸和乱伦造成的怀孕，是否应与其他情形区别对待？换句话说，遭到强奸或因近亲而怀孕，是否构成允许堕胎的特殊理由？ |
| 未成年人的父母同意 | 为未成年人实施堕胎前，是否必须征得父母同意？ |
| 政府对贫困者的援助 | 对无力自行支付堕胎费用的女性，政府是否应该通过医疗补助计划 Medicaid 为其支付？ |
| 父亲的权利 | 寻求堕胎的女性的丈夫或伴侣，是否享有任何权利？如果他反对，女性是否仍应获准堕胎？ |
| 通过宪法修正案禁止堕胎 | 是否应修改美国宪法，禁止堕胎，或从受孕之时起就把法律保护赋予尚未出生者？ |

## 示例议题：拳击

《拳台纪录年鉴》（The Ring Record Book）列出了第二次世界大战以来因职业拳赛受伤而死亡的 337 名拳击手。仅在美国，就有 120 名拳手因此丧生。[^1] 韩国拳手金得九遭到雷·“砰砰”·曼奇尼连续重击后死亡，再次点燃了一个多次引起公众关注的争议：应不应该禁止拳击？和堕胎问题一样，它实际上也包含一组较小的议题。三步法可以如下运用：

| 分题 | 具体问题 |
| --- | --- |
| 拳手谋生的权利 | 禁止拳击，是否会不公平地剥夺拳手谋生的权利？ |
| 拳击与心理健康 | 拳击比赛中的暴力表达，对拳手本人而言，是否是一种有益于情绪健康的体验？对观众呢？ |
| 拳击的受欢迎程度 | 有人说，拳击过去和现在都很受欢迎，所以应该允许它继续存在。这个论证有多大说服力？ |
| 拳击是否属于体育运动 | 把拳击归为体育运动恰当吗？参赛者以把对方打得失去知觉为目标，是否意味着它不应被列为体育运动？ |
| 消除危险 | 是否有可能通过修改规则、改进装备等方式，消除或至少减轻拳手所面临的身体危险？ |
| 遭受拳击的影响 | 一拳打在人体上，特别是头部，究竟有什么影响？十到十五个回合的比赛中，多次挨拳会产生怎样的累积影响？整个职业生涯中呢？ |

## 示例议题：青少年犯罪

在 20 世纪的大部分时期，法院对青少年罪犯采取特殊处理方式。由于重点在于帮助他们改过，而非惩罚，指控的罪名有所不同：称为“青少年违法”，而不是袭击或谋杀；程序与处理结果也不一样：举行“听证”而不是审判，封存记录而不是公开，对其训诫而不是监禁。

然而，近年来公众对这套制度日益不满。许多人要求，无论年龄多大，犯罪者都应当作为犯罪者来对待。这一宽泛议题通常表述为：“青少年罪犯是否应与成年罪犯同样对待？”但与本章讨论的其他问题一样，它也包含一组较小的议题，可以如下厘清：

| 分题 | 具体问题 |
| --- | --- |
| 青少年犯罪的原因 | 青少年违法者是否应独自为自己的犯罪行为负责？父母及社会上的其他人，例如暴力电影制作者，是否也有责任？如果他人也有责任，法律是否应对他们采取强硬措施？怎样做？ |
| 承担责任的年龄 | 一个人尚未达到能够理解自身行为在道德和法律上性质的年龄，就让他为行为负责，是否合理或公平？人到多少岁才具备这种理解能力？ |
| 青少年与成年人的异同 | 要一个十四岁、十六岁或十八岁的人，承担与二十一岁或三十岁的人相同的责任，是否合理？ |
| 公开报道对青少年犯罪的影响 | 公开年轻人的犯罪行为，是否能遏制青少年犯罪？是否有助于他们改过自新？ |
| 监禁对未成年人的影响 | 监禁对十三至十九岁的青少年会有什么影响？对更小的儿童呢？ |
| 不同犯罪的区别 | 所有青少年犯罪都应同样处理吗？对于破坏财物、商店行窃等犯罪，是否应考虑犯罪者年龄，而对强奸、谋杀等犯罪则不考虑？ |
| 再次犯罪 | 对屡次犯罪的青少年，是否应与初犯区别对待？如果是，应该怎样区别？ |
| 监狱 | 如果青少年犯罪者因暴力犯罪等原因被判入狱，是否应与成年罪犯关押在同一机构？ |

准确界定要考察的议题，不仅能使焦点更清楚、降低超出自身能力范围的可能，也能让分析本身变得容易。争夺注意力的方面越少，我们就越不容易分心或混乱。即便在少数需要全面讨论一个议题的情况下，仔细区分它所包含的各个方面，也能使探究更有条理、更有目的。最后，精确界定议题，还能减少把复杂问题过度简化的可能。

## 应用练习

### 1. 选择并厘清议题

从下列主题中选取两个，分别运用本章介绍的三个步骤。务必选择自己感兴趣的主题，因为后续章节的练习将在本次练习的基础上继续展开。

1. 是否应改革美国联邦所得税制度？
2. 在中小学开展性教育是否可取？
3. 是否应收紧离婚法律，让离婚变得更困难？
4. 精神正常的人是否可能自杀？
5. 政府是否在任何情况下有权对犯罪行为判处死刑？
6. 是否应将卖淫合法化？
7. 是否应禁止特殊利益集团进行游说？
8. 是否应禁止在儿童电视节目中投放广告，例如星期六上午的动画片节目？
9. 崇拜魔鬼的人是否精神失常？
10. 相信不明飞行物的存在是否合理？
11. 男运动员是否天生比女运动员更出色？

### 2. 重新分析议题

下列主题曾出现在第一章的应用练习中。选择一个，运用本章厘清议题的三个步骤，不考虑自己先前的分析。

1. 大一写作是否应成为所有学生的必修课？
2. 是否应检测运动员有没有使用合成代谢类固醇？
3. 高中生物课是否应该教授神创论？
4. 是否应将一夫多妻或一妻多夫的婚姻合法化？
5. 是否应把投票年龄降至十六岁？
6. 是否应允许三 K 党等极端组织在公共场所举行集会？
7. 监狱制度应该更重视惩罚囚犯，还是帮助他们改过自新？
8. 医生和诊所在为未成年人开具避孕用品时，是否应被要求通知其父母？
