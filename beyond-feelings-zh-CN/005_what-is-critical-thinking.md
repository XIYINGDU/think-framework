# 第 2 章　什么是批判性思维？

亚瑟上一年级时，老师让全班“思考”。她说：“同学们，我知道这道题比我们之前做的难一点，不过我会多给几分钟，让大家想一想。现在开始思考。”

亚瑟并非第一次听到这个词。在家里，他听过很多次，但从来不是这样的用法。老师似乎是在要求他做某种特别的事，而且他理应知道怎样开始、怎样停止，就像爸爸开车一样。“轰——”他不自觉地低声学起了发动机的声音。由于满心困惑，他根本没意识到自己出了声。“亚瑟，请别再发出怪声，开始思考。”

他很难为情，又不知道究竟该怎么做，只好低头看课桌。这时，他用眼角瞥见旁边的小女孩正盯着天花板。“也许这就是开始思考的方法。”他猜想，别人可能是在去年他得麻疹、待在家里那段时间学会的。于是，他也盯起了天花板。

从小学一路读到中学，他又听到了几百次这样的要求：“不对，答案不是这个。你根本没动脑子。现在好好想！”偶尔，还会遇到特别爱自怜、习惯自言自语的老师：“我到底做错了什么，要受这种罪？现在小学什么都不教了吗？你们对思想一点兴趣都没有？想啊，该死的，好好想！”

于是，说到思考，亚瑟总有些内疚。显然，这是件重要的事，自己却一直没学会。也许他就是脑子不够好。不过，他倒很会应付：观察别的同学，然后照着做。老师一说要思考，他就皱起脸，锁紧眉头，挠挠头，摸摸下巴，望向远处或天花板，心里反复念叨：“让我想想，我得好好想想这个问题。想，想——但愿别叫我回答——想。”亚瑟不知道，其他同学心里念叨的，也正是这些话。

亚瑟的情况并不少见，你的经历可能也差不多：许多人叫你思考，却从来没人解释过思考是什么、有多少种形式，以及善于思考的人具备哪些不善思考者所欠缺的品质。

“思考”是个统称，涵盖从白日梦到反省、分析的许多活动。《罗杰同义词词典》在 *think* 一词下列出的动词，仅举一部分，就有：

> 领会、相信、动脑、琢磨、构想、考虑、商议、凝思、斟酌、消化理解、讨论、做梦、幻想、想象、冥想、沉思、深思、意识到、推理、反省、反复思量、推测、假设、权衡。

然而，这些都只是思考的不同名称，算不上真正的解释。人类经历思考、谈论思考、书写思考已有几千年，但从许多方面看，它仍是人类存在的重大谜团之一。不过，尽管还有很多问题尚待探索，我们已经有了不少认识。

## 一个大脑，还是两个？

对大脑功能的研究揭示了左右脑之间一小束神经的重要作用。这束神经叫作胼胝体，直到不久前，人们还认为它没有什么重要功能。如今科学家知道，大脑的思考和学习中枢并非一个，而是两个。每一侧都掌管某些能力。胼胝体完好时，两侧协同运作，尽管其中一侧可能占主导；但当它被切断或受损时，左脑就不再知道右脑在做什么，反之亦然。对这类患者的实验表明：〔原文此处残缺，实验过程及眼、手之间的对应关系无法完整还原；下句按残存文字翻译。〕由“看不见”的那只眼睛所控制的手，后来无法凭触觉认出该物体。对大脑的一部分来说，这件物体很熟悉；对另一部分来说，却完全陌生。[^1]

我们现在还知道，左右脑各有自己的记忆和思路。左脑主要处理文字，与分析和逻辑思维有关；右脑主要处理感官图像，与直觉和创造性思维有关。[^2] 不过，尽管两侧大脑半球有所分工，脑的各项功能仍高度整合。

一些研究者把大脑与心智视为同一回事。西方哲学的传统观点却认为，二者存在重要差别：大脑是物质实体，心智则属于形而上的、非物质的存在。

## 批判性思维的定义

“批判”一词常带有负面意味，让人想到过分挑剔。但“批判性思维”并没有这层意思，它指的是评价观念的过程。进行批判性思考时，我们要判断说法是否准确，以及得出结论的推理是否站得住脚。批判性思维帮助我们理解复杂观念，评估支持论证的证据，并区分什么合理、什么不合理。解决问题、作出决策，以及有意义地讨论争议问题，都离不开批判性思维。

熟练掌握批判性思维的关键之一，是善于提出切题的问题。不加批判的人会直接接受自己的第一反应和他人的说法，而批判性思考者则会像下面这样，审视各种想法：

| 想法 | 应当追问的问题 |
| --- | --- |
| 维尔教授给我的写作课成绩不公平。他让某些作文在总分中占的比重高于其他作文。 | 他给每个人评分时，用的是同一套标准吗？不同作文所占比重不同，有合理理由吗？ |
| 妇女进入职场以前，离婚少得多。这说明女人就该待在家里。 | 你怎么知道离婚增多是由这个因素，而不是其他因素造成的？ |
| 大学教育不值那么多钱。有些人的工资，始终没比他们不拿学位时可能挣到的高多少。 | 钱是衡量教育价值的唯一标准吗？更好地理解自我与人生，以及更有能力应对挑战，这些价值又怎么算？ |

批判性思考者还会用提问来作哲学层面的探究：对问题保持好奇，追问得比通常更深入，寻求新的认识。以“价值观”为例。今天我们经常听到这样的说法：“我们的国家已经丢掉了传统价值观。”或者：“如果家长和教师更重视道德价值观，犯罪就会减少，尤其是暴力犯罪。”批判性思考者会提出如下问题：

- 价值观与信念是什么关系？与坚信不疑的观念又是什么关系？
- 所有价值观都有价值吗？
- 一般人对自己的价值观了解多少？许多人会不会连自己真正的价值观是什么都在自欺？
- 一个人的价值观从何而来？来自个人内部，还是外界？来自思考，还是感受？
- 教育会改变一个人的价值观吗？如果会，这种改变总是变好吗？
- 家长和教师是否应该尝试塑造儿童的价值观？

## 批判性思考者的特征

关于批判性思维，有不少误解。第一种误解是：只要能为自己的信念提供理由，就算具备了批判性思维。然而，几乎每个人都有理由，哪怕那些理由实在站不住脚。检验批判性思维的标准，是理由是否可靠而充分。

另一种误解是：批判性思考者从不在思想或行动上模仿别人。如果真是这样，每个顽固不化的人都能算批判性思考者了。批判性思维意味着作出明智的决定，无论这些决定与多少人相同。

第三种误解是：批判性思维就是脑子里装了很多正确答案。知道正确答案当然没有坏处，但批判性思维指的是在答案并不现成时，寻找答案的过程。

还有一种误解是：批判性思维学不会，一个人要么天生“有”，要么没有。事实恰恰相反，批判性思维关乎习惯。即使是最粗心、最马虎的思考者，也能通过培养相应品质，成为批判性思考者。

我们已经谈到其中一项特征：善于提出恰当的问题。另一项则是能够掌控自己的思维活动。美国哲学家约翰·杜威曾说，我们花在“摆弄脑海中的画面、零散的回忆、美好却毫无根据的希望，以及一闪而过、尚未成形的印象”上的时间，比大多数人愿意承认的多得多。[^3] 善于思考的人也不例外。不过，比起不善思考的人，他们更懂得在需要时停止这种随意、半自觉的意象漂移，把注意力放到一件具体事情上，仔细考察，并作出判断。换句话说，他们学会了掌控自己的思想，既能被动接收，也能主动运用心智。

下面再把两类人的一些特征作个对照：

| 批判性思考者 | 缺乏批判性思维的人 |
| --- | --- |
| 对自己诚实，承认有所不知，认识自己的局限，并留意自己可能犯的错误。 | 不懂装懂，忽视自身局限，认定自己的看法不会错。 |
| 把难题和争议看作令人振奋的挑战。 | 把难题和争议视为麻烦，或视为对自尊的威胁。 |
| 努力求得理解，保持好奇，耐心面对复杂问题，愿意投入时间消除困惑。 | 对复杂问题缺乏耐心，宁可继续糊涂，也不愿下功夫弄懂。 |
| 放下个人偏好，依据证据判断；证据不足时暂缓判断；新证据揭示错误时，修改判断。 | 凭第一印象和直觉反应判断，不在意证据的数量与质量，始终固守原有看法。 |
| 对别人的想法感兴趣，即使不太赞同，也愿意认真阅读和倾听。 | 只顾自己和自己的意见，不愿留意他人的观点；一遇到分歧就想：“我该怎么反驳？” |
| 认识到极端观点，无论保守还是自由派，往往不正确，因此避免走极端，公正看待问题，寻求平衡的认识。 | 忽视平衡的必要性，偏爱支持自己既有看法的观点。 |
| 懂得克制，掌控感受而不受感受支配，行动前先思考。 | 容易跟着感受走，冲动行事。 |

这些可取的品质说明，批判性思维依赖对思维的自我约束。善于思考的人掌控自己的精神活动，引导思想，而不是被思想牵着走；在检验并证实一个观念以前，即便那是自己的观念，也不贸然赞同。杜威把这种自我约束视为自由本身。他认为，不具备它的人并不自由，而是奴隶。他这样写道：

> 如果一个人的行动不受深思熟虑所得结论的指引，就会受不经思考的冲动、失去节制的欲望、一时的任性或眼前处境所支配。鼓励不受约束、不经反省的外在活动，就是助长奴役，因为这会使人听任欲望、感官和处境的摆布。[^4]

## 直觉的作用

直觉是不经过理性推演便产生的本能认识或感知。在思维的种种表现中，它也许最富戏剧性，因此也最令人着迷。历史上记载了许多重要发现“突然浮现”在人们脑海中的例子。当事人甚至可能并未有意识地考虑那个问题，答案却一下子出现了，仿佛凭空而来。

德国化学家凯库勒就是这样解决了一道化学难题。极度疲倦时，他进入了白日梦般的状态，脑海里出现一条蛇咬住自己尾巴的画面。这给他提供了关于苯分子结构的线索：其中的原子组成的是环，而不是链。[^5] 德国作家歌德曾为一部作品整理大量材料，迟迟无法安排妥当。后来，他得知一位好友自杀的噩耗；就在那一瞬间，组织这些材料的完整构思浮现在他脑海中。[^6] 英国诗人柯勒律治——你在中学时可能读过他的《古舟子咏》——曾从梦中醒来，脑中清清楚楚地留着一首新的、复杂诗作的两三百行诗句。

直觉并非名人的专利。我们大多数人也有过类似的体验，只是没那么惊天动地。这些体验无论大小，都有两个共同点：一是直觉无法控制，二是直觉并不完全可靠。即使最强烈的直觉，也可能被证明是错的。出于这两点，直觉虽然始终是批判性思维中可喜的助力，却永远不能取代它。当然，这也不必令人担心，因为许多其他思维技能都是可以掌控和培养的。

## 批判性思维与写作

写作大致有两种目的：发现想法，或传达想法。你在学校做过的写作，无疑多半属于后者。不过，前者也很有用：它不仅能理清已经产生的想法，还能激发更多想法。不知为什么，只要把一个想法写下来，往往就会引出新的想法。

为发现想法而写作时，要把注意力放在正在考察的问题上，并记录所有念头，既包括判断，也包括疑问。不要顾虑组织得好不好、写得对不对。如果想法来得慢，就耐心等；如果突然大量涌现，也不要急着放慢速度、展开其中一个，而应先全部记下来。（以后有的是时间展开和修改。）要有意识地引导思考，同时也留意意识边缘那些隐约的念头；它们往往同样有价值。

如果这种探索性的写作做得充分，你又对写出的想法进行了批判性思考，那么接下来，为传达观点而写作就会更容易，也更愉快。你会有更多经过检验、站得住脚的想法可供展开和组织。

## 应用练习

1. 你在学校学习思考的经历，与亚瑟的经历有多相似？

2. 你觉得深入思考重要问题很困难吗？能否避免随意、半自觉漂移的脑海画面打断思路？在某些情境下，你是否比在其他情境下更难控制注意力？请说明。

3. 对照前表中善于思考者的七项特征，逐项评价自己。你最强的是哪项，最弱的又是哪项？如果表现因情境而异，试着弄清哪些问题或处境会激发你最好或最差的思维品质。

4. 你思考难题或争议时，有没有某种固定模式？最先进入脑海的是画面，还是一个词？接下来是什么？再接下来呢？如果不能完整回答，就做这个练习：把本书向后翻五六页，随机选一句话，读完后留意自己的头脑怎样处理它。（这种对自身思考的观察，起初可能有点别扭；如果如此，不妨试两三遍。）

5. 仔细阅读以下说法，判断一个善于批判性思考的人是否需要提问；如果需要，哪些问题值得问？

   1. 电视新闻报道战争时耸人听闻，因为它只向我们展示受伤、死亡和破坏的画面。
   2. 我父母太严了，十六岁以前都不许我约会。
   3. 显然，拉尔夫不喜欢我——我们在走廊擦肩而过时，他连话都不说。
   4. 某新闻电视网的广告说：“新闻每分钟都在变化，所以你需要不断接收更新，才能及时了解情况。”
   5. 阿拉巴马州一所公立小学的教师让学生背诵《主祷文》，并在饭前祷告。他说：“我觉得教师职责的一部分，就是向孩子灌输过上美好生活所需的价值观。”[^7]

6. 运用本章所学，阐明你对以下各项争议的立场，并说明理由。

   1. 某些州的强奸法规定，行为人使用的暴力必须足以使受害人担心遭受严重身体伤害或死亡。某些法律还要求受害人确实奋力反抗。如果不具备这些条件，就不会对强奸者提起公诉。
   2. “改善电视联盟”呼吁公众抵制美国无线电公司（RCA）的产品，理由是该公司旗下的全国广播公司（NBC）“把基督徒角色、基督教价值观和基督教文化排除在节目之外”。这被认为是首次在全国范围内试图施加经济压力，迫使电视网减少节目中的性与暴力内容。NBC 谴责这一行动是“明目张胆的恐吓”。[^8]
   3. 近年来，青少年甚至年幼儿童实施的暴力犯罪增多，因此许多人主张，刑事司法制度应把少年犯当作成人处理。还有人认为，罪行最严重者应被判处死刑。
   4. 1989 年，乔治·布什总统公开反对一项禁止突击步枪的提案。他的观点支持了全国步枪协会的立场，即持有武器的权利不应受到削减。许多警察组织强烈反对这一立场。
   5. 美国最高法院审理过两名犯下恶性罪行的少年的案件。其中一名十七岁，强奸并杀害了一名加油站工作人员；另一名十六岁，向一位酒类商店女店主连刺八刀，致其死亡。许多人认为，这类案件判处死刑是适当的；另一些人则认为，无论犯了什么罪，对未成年人判死刑都不合适。[^9]
   6. 一名精神状态不稳定的男子给阿拉巴马州一家电视台的新闻编辑室打电话，威胁要自杀。电视台通知警方后，派了摄制组到现场。据报道，该男子往身上浇打火机油，划了两根火柴，想点燃自己但没有成功，而摄制组一直在旁拍摄。直到第三次点燃成功，他们才上前阻止。此后，电视台播出了这段画面。摄制组一名成员解释说：“我的工作就是如实记录正在发生的事件。”许多人认为摄制组的处置有问题。[^10]
