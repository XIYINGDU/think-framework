# 第 22 章　形成判断

判断，是通过考察证据和审慎推理得出的结论，是思考的产物。与感受不同，判断并非自发、无意识地产生。当然，它也可能包含直觉等自发成分，但这些成分和其他资料一样，都已经过权衡与评价。

判断来自评价与推理，并不保证它一定有价值。判断有明智的，也有愚蠢的；有深刻的，也有肤浅的。它很容易反映出对真理、知识和看法的误解，也可能包含第六至第十五章详细讨论过的一种或多种思维错误。

我们讨论的批判性思维策略，目的就是帮助人形成经过深思熟虑的判断。认识自己、善于观察，能改善我们的感知，防范错误；有步骤地厘清议题、开展探究、解释证据、分析观点，则能使思考摆脱先入之见和第一印象。

把判断表达出来的过程，本身就可能改变判断。因此，不管某个判断在脑中显得多么清楚，在用语言表达之前，最好都把它视为尚未成形。以下准则有助于有效表达判断：

- 力求全面而均衡地看待问题。
- 无法确定时，说明可能性。
- 让主语的范围恰当而具体。
- 让谓语准确表达本意。
- 加入一切必要的限定。
- 避免夸大。

下面逐项讨论。

## 力求全面而均衡地看待问题

均衡的观点，能够反映议题全部的细微之处和复杂性。占主导地位的看法，会对大多数人的思考产生强大影响；当议题充满争议、人们情绪激动时，尤其如此。人们往往不知不觉地采用同样的角度、同样的论据，甚至同样的措辞。平时善于批判性思考的人，也会这样。

这时，一群自由派思想者听起来如出一辙，一群保守派思想者也一样。直到有人终于以自觉的思维约束打破模式，均衡地审视问题，才会出现令人耳目一新、富有独创性，而且往往颇有洞见的看法。

以萨尔曼·鲁西迪的小说《撒旦诗篇》为例。由于该书嘲弄伊斯兰教及先知穆罕默德，使穆斯林深感受辱，他们愤怒地作出反应。阿亚图拉霍梅尼甚至悬赏追杀作者，并威胁所有参与出版或发行该书的人。无论按什么标准衡量，这都是极端的反应，而它又激起了另一种激烈回应。人们举行集会，以各种方式支持作者及出版商。

绝大多数写作者和发言者都围绕“表达自由”这一口号展开论证。这无疑是一条值得捍卫的原则，也确实受到了霍梅尼及其追随者的威胁。但值得捍卫的原则不止这一条。少数作者克制住了加入大合唱的冲动，提醒人们注意另一条当时几乎被遗忘的原则：尊重他人的宗教信仰。

专栏作家约翰·利奥谈到：“我们的宽容原则，要求在讨论他人的宗教信仰时，保持一定的尊重与自我克制。”[^1] 圣十字学院教授约翰·埃斯波西托也指出：“第一修正案赋予的权利，并不意味着想说什么就理应全说出来。”[^2]

再来看培养自尊的问题。二十多年来，自我提升类书籍的作者一直强调自尊的重要性，尤其强调应从幼儿开始培养。这种强调如此强烈，以至于许多人认为，人在学校和日后生活中成功还是失败，主要取决于自尊。几乎任何让人自我感觉良好的努力，都会赢得赞许。

但心理学家兼律师芭芭拉·勒纳抵制住了主流看法的强大吸引力，对自尊作了审慎考察。她由此发现，自尊并不总是好事，有时还可能妨碍成就。她指出，“凭努力赢得的自尊”与“立刻让自己感觉良好”的自尊有区别。前者能推动人取得成就，甚至走向卓越；后者却会让人自满，最终导致无能。[^3]

要全面而均衡地看待所讨论的议题，就必须愿意寻找被忽视的一面，并在有充分理由时，挑战占主导地位的看法。

## 无法确定时，说明可能性

即使竭尽所能调查，有时仍无法积累足够证据，作出确定无疑的判断。争议问题尤其如此。这时，不负责任的人往往会提高嗓门，使用更强硬的措辞，装作胸有成竹。这是严重的错误：首先，这种装出来的确定性很少骗得过善于思考的人；更重要的是，它在求知态度上是不诚实的。

只要真诚努力过，试图取得作出确定判断所需的证据，又不是故意骑墙，那么承认“在这种情况下，我无法确切断定什么判断才正确”，并没有什么可羞愧的。恰恰相反，这是一种优点。

不过，作为负责任的思考者，我们还有进一步的义务：如果可能，说明从可能性来看，哪种判断更有依据。也就是说，要说明证据虽然未能证明、却暗示了什么判断可能正确。

例如，证据也许还不足以让人确定地说，吸烟会导致肺癌，或者观看电视中的暴力内容一定会对人造成伤害。不过，在这两个问题上，已有足够证据支持我们判断可能存在的因果关系。

凡是无法达到确定性的时候，就把重点放在可能性上。

## 让主语的范围恰当而具体

审慎的判断，其主语范围应当恰当而具体。比较以下句子：

1. 如今的大学生，对语法和语言用法的掌握不如十年前的大学生。
2. 如今美国的大学生，对语法和语言用法的掌握不如十年前的美国大学生。
3. 如今美国两年制大学的学生，对语法和语言用法的掌握不如十年前同类院校的学生。
4. 如今这所大学的学生，对语法和语言用法的掌握不如十年前本校的学生。

如果证据只涉及某一所大学的学生，那么只有最后一个判断可能成立。其余三个都概括得过宽。要避免在写作或说话中犯这种错误，就应仔细选择判断所指的对象和范围。

## 让谓语准确表达本意

审慎判断中的谓语，应当准确表达你想作出的断言。比较以下句子：

| 英文例句 | 中文含义 |
| --- | --- |
| Peace has been achieved. | 和平已经实现。 |
| Peace can be achieved. | 和平能够实现。 |
| Peace must be achieved. | 必须实现和平。 |
| Peace should be achieved. | 应当实现和平。 |
| Peace could be achieved. | 和平或许能够实现。 |
| Peace will be achieved. | 和平将会实现。 |

这些句子的结构非常相似，意思却大不一样。除非故意使用歧义表达，那样就应预料到会引起困惑，否则都应该审慎选择谓语。

“上帝死了”这句话曾在 20 世纪 60 年代引发神学争论，是歧义造成混乱的一个好例子。作为口号，它很出色，但究竟是什么意思？单独看这句话，很难回答。除了最明显的一种可能解释——“不存在至高无上的神”——至少还有七种：

1. 人们不再愿意相信上帝存在。
2. 人们已经无法相信上帝存在。
3. 人们不再确定上帝是否存在。
4. 人们的行为不再以相信上帝存在为前提。
5. 人们不再关心上帝是否存在。
6. 人们不再接受某一种特定的上帝观念。
7. 人们不再满足于传统方式的局限，认为人类惯用的那些说法，已不足以表达对上帝存在的信仰。

如果希望自己的意思得到理解，最好从上述句子中选择能清楚表达判断的一句，或另用其他明确说法，而不要只说“上帝死了”。

## 加入一切必要的限定

说某件事“通常发生”，不同于说它“经常发生”，也不同于说它“每隔一个星期二发生”。越认真补足必要限定，让话语不多不少地表达本意，判断就越可能经得起辩护。这不仅包括时间限定，也包括地点和条件限定。

来看这个判断：“四十岁以上、从未上过大学的美国男性，往往反对全国妇女组织所倡导的妇女解放观念。”这句话可能正确，也可能不正确，但几乎每一个词都起着限定作用。它说的是：

- 美国男性，而不是所有男性。
- 四十岁以上且从未上过大学的人，而不是所有年龄、所有教育程度的人。
- 全国妇女组织倡导的妇女解放观念，而不是笼统意义上的妇女解放。

## 避免夸大

我们大多认识这样一两个人：在他们口中，每个场合都“令人难忘”，每个问题都是“危机”，每部好看的电影都“值得提名奥斯卡”，每款漂亮的新车或新时装都“无与伦比”。对他们来说，没有什么仅仅是好或坏，而一定是最好或最坏。他们的词汇充满最高级。别人约会迟到了，他们就说自己等得“天荒地老”；去看牙医，疼痛就“难以忍受”；欠了债，债务就成了“天文数字”。

听这种人讲述，我们得先在心里翻译一遍，把尺度缩回现实范围。如果他们说：“他是我见过最高大的人，至少有七英尺十英寸！”我们就判断，大概六英尺六英寸吧。如果他们说：“你一定要听西德尼·斯克里奇的新唱片，这是他有史以来最精彩的演出！”我们就判断，大概比平时好一点。

如果夸大其词的是亲密朋友，我们通常愿意做这种翻译，但也可能厌倦无休止的最高级。如果只是普通熟人，或只是通过其文字和演说认识的人，我们的耐心就更少了。我们难免降低对他们的信任，觉得他们不能准确判断周围世界；而且，他们的眼光似乎失去平衡，缺乏必要的分寸感。

如果希望自己的判断经得起他人检视，就应避免这类夸大。拿不准判断是否准确时，宁可说得保守些，也不要过头。也就是说，选择较谦抑的解释、较不极端的结论。这样，即使错了——任何人都难免有时犯错——至少还保留了一点可取之处：你表现出了自制与克制。

如果你的判断符合本章介绍的标准，就可以为之自豪。经过审慎思考形成的判断，是人类的鲜明标志，也是思维能力的最高体现。它使人类与其他生物显著区别开来，使我们不断增长知识，更重要的是增长智慧，并改善自己和他人的生活。
