# think-framework

Personal thinking and research guides, distilled from two books:

- `_vincent` — Vincent Ryan Ruggiero, *Beyond Feelings*
- `_williams` — Booth, Colomb, Williams, Bizup, and FitzGerald, *The Craft of Research* (5th ed.)

Method lives in `*/derived/actionable-principles.md`. Runtime wrappers are under `.claude/`, `.codex/`, and `.grok/`.

Session memory is on disk, not in the chat: `.claude/state/current-focus.md` is injected on startup, resume, `/clear`, and compact.
